# Кузница — ежедневные тренировки

Домашние тренировки с гантелями, превращённые в игру: у каждого дня недели своя группа мышц, каждый подход записывается, а за работу капают опыт, уровни и ранги E→S.

## Игра живёт здесь

https://vladislavbropiton.github.io/game/

Открывается с компьютера и с телефона, интернет нужен только при первом заходе.

## Что внутри

**Задание дня.** Игра сама знает, что сегодня тренируем:

| День | Группа |
|---|---|
| Понедельник | Бицепс |
| Вторник | Спина |
| Среда | Плечи |
| Четверг | Ноги |
| Пятница | Трицепс |
| Суббота | Грудь |
| Воскресенье | Предплечья |

Расписание меняется в профиле — можно переставить группы как удобно, прошлые записи при этом не трогаются.

**Запись подходов.** Выбираете упражнение из списка (5–7 вариантов на группу) или вписываете своё. Дальше записываете каждый подход: вес и повторы. После подхода запускается отсчёт отдыха.

**Как выполнять и что работает.** У каждого упражнения есть разбор: анатомическая иллюстрация тела спереди и сзади с подсветкой работающих мышц (основные ярко, вспомогательные приглушённо), техника по шагам и частая ошибка. По нажатию схема открывается крупно.

Иллюстрация мышечной системы взята из учебника **OpenStax Anatomy & Physiology** (лицензия CC BY 4.0), подписи и линии-выноски убраны, фон сделан прозрачным. Файлы лежат в `img/` и кэшируются для работы без интернета.

**Рекорды.** Игра помнит, что вы делали в прошлый раз, и подсвечивает подход, который побил личный рекорд: больший вес — или то же железо, но больше повторов.

**Потолок снаряда.** В профиле задаётся максимальный вес одной гантели (по умолчанию 15 кг). Пока вес можно добавить, игра предлагает вес. На потолке она переключается на повторы: рекордом становится каждый лишний повтор, а подсказка предлагает способ усложнить подход без железа — медленное опускание, пауза внизу, короткий отдых, работа одной рукой.

**Опыт и ранги.** За тренировку: 60 за явку, плюс за объём (вес × повторы), 25 за каждый рекорд и бонус за серию дней. Ранги: E «Пробуждённый» → D «Охотник» → C «Ветеран» → B «Элита» → A «Мастер» → S «Монарх».

**Серия дней.** Считается серия ежедневных тренировок, один пропуск прощается — иначе одна занятая среда обнуляет месяц.

**Навигация.** Между экранами — нижнее меню на телефоне и верхнее на компьютере. На экране тренировки есть кнопка «← К списку упражнений» (с записанными подходами она спросит: остаться, засчитать тренировку или выбросить). Системная кнопка «назад» на телефоне сначала закрывает окно, потом возвращает на прошлый экран.

**Экраны.** Статус (ранг, кольцо дня, неделя, вызов недели), Тренировка, Журнал (все тренировки по дням), Сила (рекорды и объём по неделям), Профиль (календарь на 12 недель, достижения, расписание, настройки).

**Достижения.** 19 штук: первая тренировка, неделя без пропусков, идеальная неделя (все семь дней), железная привычка (серия 30 дней), сотня подходов, десять тонн, полный круг по всем группам, а также четыре про повторы — «Пятнадцать на пятнадцати», «Двадцатка», «Сотня за тренировку» и «Пять тысяч повторов».

**Хроники Системы.** 54 коротких истории про 32 человек — Сталлоне, Шварценеггер, Джеки Чан, Брюс Ли, Али, Тайсон, Карелин, Власов, Поддубный, Засс, Хабиб, Роналду, Коби, Джордан, Фелпс, Бубка, Гоггинс и другие. У каждого героя фотография: она подгружается из Викимедиа, лицензия и автор подписаны прямо в окне. Без интернета вместо фото показывается значок, текст остаётся на месте.

Записи открываются по мере тренировок: первая — после первой, последняя — после 237-й. У одного героя может быть несколько разных историй.

## Установка на телефон

Игра ставится на домашний экран как обычное приложение: своя иконка, запуск на весь экран, работа без интернета.

**Android (Chrome):** открыть ссылку → меню «⋮» → «Установить приложение».

**iPhone (только Safari, в Chrome такого пункта нет):** открыть ссылку → «Поделиться» → «На экран Домой».

## Перенос прогресса между устройствами

Прогресс хранится в браузере того устройства, где вы тренируетесь: на телефоне и компьютере он свой. Чтобы перенести:

1. Профиль → «Код синхронизации» → «Скопировать».
2. На другом устройстве: Профиль → «Загрузить код» → вставить.

Игра хранит одну версию сохранения назад — если что-то сломается, в профиле есть «Откатить сохранение». Единственная полная резервная копия — это код синхронизации, скопированный себе в заметки.

## Состав репозитория

| Файл | Зачем |
|---|---|
| `index.html` | вся игра: разметка, стили и логика в одном файле, без библиотек |
| `manifest.json` | описание приложения для установки на телефон |
| `sw.js` | офлайн-режим |
| `icon-*.png`, `apple-touch-icon.png` | иконки приложения |
| `img/body-front.webp`, `img/body-back.webp` | анатомические иллюстрации (OpenStax, CC BY 4.0) |

Никаких сборщиков и зависимостей: `index.html` открывается двойным кликом и работает сам по себе.
