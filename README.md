# Кузница — игра-план развития

## Игра живёт здесь

https://vladislavbropiton.github.io/game/

Открывается с компьютера и с телефона, интернет нужен только при первом заходе.

## Установка на телефон

Игра поставится на домашний экран как обычное приложение: своя иконка, запуск на весь экран без адресной строки браузера, работа без интернета.

**Android (Chrome):** открыть ссылку → меню «⋮» → «Установить приложение» или «Добавить на главный экран».

**iPhone (только Safari, в Chrome пункта нет):** открыть ссылку → кнопка «Поделиться» → «На экран Домой».

После установки игра запускается с иконки и работает офлайн — страница и иконки лежат в кэше телефона. При появлении интернета сама подтягивает свежую версию.

## Как открыть

**На компьютере.** Двойной клик по `index.html` — откроется в браузере. Больше ничего не нужно: ни сервера, ни интернета.

**На телефоне.** Файл лежит на компьютере, поэтому с телефона он сам по себе не откроется. Два способа:

1. **GitHub Pages** (рекомендую, 10 минут). Создать репозиторий, положить туда `index.html`, включить Pages в настройках — получится ссылка вида `https://ваш-логин.github.io/forge/`. Открывается откуда угодно, можно добавить на домашний экран как приложение.
2. **Быстро и грязно.** Отправить `index.html` самому себе в Telegram и открывать оттуда. Прогресс на телефоне будет свой — переносится кодом синхронизации.

## Как переносить прогресс

Прогресс хранится в браузере того устройства, где вы играете. Чтобы продолжить на другом:

1. Профиль → **Код синхронизации** → Скопировать
2. На другом устройстве: Профиль → **Загрузить код** → вставить

Даже на GitHub Pages прогресс не синхронизируется сам — браузеры хранят его отдельно. Автоматический синк через Supabase появится в сезоне 2, отдельным квестом: заодно и научит.

## Правила

- 📖 **изучить** — отметил и пошёл дальше, XP небольшой
- 🔨 **сделать** — не засчитается без пруфа: ссылка на коммит, деплой, скриншот
- 👑 **босс** — крупный артефакт, который можно показывать клиенту

Квест открывается, когда закрыты те, от которых он зависит. Сезон открывается, когда предыдущий пройден на 70%. На экране «Дерево» видно, какая именно зависимость держит нужный квест.

Фон — нарисованный портал с частицами. Если мешает читать, в профиле есть кнопка «Фон: врата» — выключает его вместе с частицами, выбор запоминается.

У каждого квеста есть таймер — кнопка «Начать». Пользоваться им необязательно: без него время берётся из оценки в плане. Но если включать, через месяц будет видно, насколько оценки расходятся с вашей реальностью, и план можно пересобрать по фактическим цифрам.

## Картинки

Игра ищет арт в папке `art/` рядом с `index.html`. Пока её не заполнили — работает на значках рангов и эмодзи, и не делает лишних запросов: проверка идёт по одному файлу-маркеру `art/rank-e.png`.

Что можно сгенерировать и точные промпты под каждую картинку — в `ART.md`.

## Если что-то пошло не так

Прогресс живёт в браузере, и браузер иногда его теряет. Игра к этому готова: хранит одну версию назад, при повреждении поднимает её и говорит об этом. Если испорчены обе версии — перестаёт сохранять, чтобы не затереть остатки, и просит загрузить код синхронизации.

Поэтому одно правило: **иногда берите код синхронизации** (Профиль → «Код синхронизации») и держите его где-нибудь. Это единственная полная резервная копия.

В профиле также есть «Откатить сохранение» — вернуть предыдущую версию вручную, если случайно снесли лишнее.

## Что где лежит

Эта папка — то, что уезжает на GitHub, и ничего лишнего:

| Файл | Зачем |
|---|---|
| `index.html` | вся игра: разметка, стили, данные квестов, логика |
| `manifest.json` | описание приложения для установки на телефон |
| `sw.js` | офлайн-режим |
| `icon-192.png`, `icon-512.png`, `icon-maskable-512.png` | иконки приложения |
| `apple-touch-icon.png` | иконка для iPhone |
| `art/` | сюда кладутся картинки из Krea, промпты — в `ART.md` уровнем выше |
| `README.md` | этот файл |

Рабочие материалы лежат **рядом, в родительской папке `Развитие`, и в репозиторий не входят**:

- `ANALYSIS.md` — разбор стартовой позиции: что есть в проектах, чего нет
- `GAME-DESIGN.md` — концепция, ветки, механики
- `ROADMAP.md` — все квесты текстом, читается без игры
- `ART.md` — промпты для генерации картинок
- `notes/` — заметки, которые заполняются по ходу квестов

Так сделано намеренно: `ANALYSIS.md` и `notes/` содержат личное — разбор слабых мест, будущие цены, каналы клиентов, способ приёма денег. Репозиторий на бесплатном плане GitHub публичный, и всё это увидел бы любой.

## Если игра начнёт давить

Значит сломана игра, а не вы. Приходите — перенастроим темп, XP или состав квестов. План должен подстраиваться под жизнь, а не наоборот.
