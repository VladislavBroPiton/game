Ролики в приложении
===================

Способов два.

1) Свои файлы прямо с телефона (ничего никуда не выкладывается)
---------------------------------------------------------------
Открыть раздел «Видео» → «Добавить видео» → выбрать файлы.
Они сохранятся внутри приложения на этом устройстве, будут работать
без интернета и не попадут в интернет вообще. Это правильный способ
для роликов, скачанных из сети: чужое видео нельзя выкладывать в
открытый репозиторий, а держать копию для себя — можно.

Ограничение: записи живут, пока браузер хранит данные сайта. Если
очистить данные — список опустеет, файлы на телефоне останутся.
На телефоне разумный объём — до нескольких сотен мегабайт.

2) Ролики, которые едут вместе с приложением
---------------------------------------------
Положить файл .mp4 в эту папку и описать его в list.json:

[
  { "f": "zhim-lezha.mp4", "n": "Жим лёжа: техника", "c": "Грудь",
    "d": "Лопатки сведены, локти под углом 45°" },
  { "f": "razminka.mp4",   "n": "Разминка плеч",     "c": "Разминка" }
]

  f — имя файла в этой папке
  n — название в списке
  c — раздел (любое слово: «Грудь», «Техника», «Разминка»)
  d — короткое пояснение, можно не писать

Такие ролики видны всем, кто откроет сайт, поэтому сюда кладут только
то, что снято самостоятельно или разрешено к публикации. Размер файла
на GitHub — до 100 МБ, и лучше держаться в пределах 20–30 МБ: иначе
страница будет долго открываться.

Перед заливкой стоит сжать ролик, например так:
  ffmpeg -i исходник.mp4 -vf scale=-2:720 -c:v libx264 -crf 28 -c:a aac -b:a 96k готовый.mp4
